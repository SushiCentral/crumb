# File tree icons

Curated SVG assets from Material Icon Theme, release v5.20.0.

Source: https://github.com/material-extensions/vscode-material-icon-theme/tree/v5.20.0/icons
License: MIT (see LICENSE.txt).

Bundled locally with upstream colors and paths; no runtime network requests.

The upstream `folder-base.svg` and `folder-base-open.svg` are stored as
`folder.svg` and `folder-open.svg` respectively; SVG contents are unchanged.
